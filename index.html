Como hospedar no GitHub Pages gratuitamente

1 Crie um repositório no GitHub
No seu perfil do GitHub, clique em New Repository, dê um nome (por exemplo: corte-etiquetas) e deixe como Public.
2 Envie os arquivos para o repositório
Abra o terminal nesta pasta do projeto e execute os comandos:
git init
git add .
git commit -m "Publicação CorteFácil PDF"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/corte-etiquetas.git
git push -u origin main
3 Ative o GitHub Pages
No seu repositório no GitHub, acesse Settings > Pages.
Em Build and deployment > Branch, selecione main e a pasta / (root), depois clique em Save.
Em cerca de 1 minuto, seu aplicativo estará online com um link público como:
https://SEU-USUARIO.github.io/corte-etiquetas/
Pronto!
